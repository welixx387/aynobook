# AynoBook

Закрытая домашняя библиотека-читалка в холодной монохромной эстетике. Работает как страница-артефакт в Claude: вход через аккаунт Claude, книги и пометки хранятся в базе данных артефакта.

## Возможности

**Для читателя**
- Читательский билет: регистрация без пароля, вход и выход.
- Полка с поиском, фильтрами и сортировкой, блок «Продолжить чтение».
- Читалка: режим страниц (с разворотом на широком экране) и режим ленты, листание кликом, свайпом, стрелками и колесом.
- Закладки-ленточки, выделения четырьмя цветами, заметки на полях, поиск по книге, оглавление.
- Шесть тем страницы, четыре шрифта, кегль, интерлиньяж, поля, выключка, красная строка.
- Вкладка «Цитаты»: каждая цитата показывается читателю один раз, повторов на одном аккаунте нет.

**Для библиотекаря (владельца)**
- Загрузка FB2, FB2.ZIP, EPUB, TXT (в том числе в кодировках Windows-1251 и KOI8-R), PDF с текстовым слоем, HTML и Markdown. Файл разбирается в браузере: название, автор, аннотация, обложка, главы.
- Редактирование карточки книги, смена обложки, скрытие от читателей, удаление.
- Управление списком цитат.

## Структура

```
src/            исходники страницы, собираются в один файл по порядку
  01_head.html  заголовок, шрифты, все стили
  02_body.html  разметка: вход, приложение, читалка
  03_core.js    утилиты, анимация доски, хранение данных, вход, навигация
  04_views.js   полка, карточка книги, закладки, цитаты, раздел библиотекаря
  05_parse.js   разбор форматов книг
  06_reader.js  движок читалки: вёрстка страниц, закладки, выделения, поиск, настройки
  07_end.js     запуск
dist/aynobook.html  собранная страница
seed/           встроенная книга-путеводитель и стартовый набор цитат
test/           локальная проверка в Playwright с имитацией платформы Claude
build.sh        сборка
```

## Сборка

```sh
./build.sh
```

Результат: `dist/aynobook.html`. Этот файл публикуется как артефакт в Claude.

## Где хранятся данные

Страница использует возможности артефактов Claude:

| Путь в базе | Что хранится | Кто пишет |
|---|---|---|
| `books/<id>` | карточка книги и оглавление | только владелец |
| `books/<id>/parts/<n>` | текст книги частями, если файловое хранилище недоступно | только владелец |
| `lib/quotes` | список цитат | только владелец |
| `data/users/<id>/profile` | читательский билет и настройки | сам читатель |
| `data/users/<id>/b_<книга>` | место чтения, закладки, выделения, заметки | сам читатель |
| `data/users/<id>/quotes` | какие цитаты читатель уже видел | сам читатель |

Текст книг и обложки лежат в файловом хранилище артефакта (`/_blob/<id>`). Правила доступа при публикации:

```json
{"db": {"rules": [
  {"path": "", "read": "view", "write": "owner"},
  {"path": "data/users/{self}", "write": "interact"}
]}, "user": {"scopes": ["profile"]}, "assets": {}}
```

Читатель с доступом только на просмотр может читать, но его пометки сохраняются в браузере, а не в базе.

## Локальная проверка

Нужны Python, Playwright и Chromium.

```sh
cd test
python3 make_files.py   # создаёт пробные EPUB, FB2 и TXT
python3 run.py          # полный прогон: вход, загрузка, чтение, закладки
python3 run_q.py        # проверка вкладки «Цитаты»
```

Скриншоты сохраняются в `test/shots/`. Скрипты подменяют платформу Claude имитацией из `test/mock.js`.
